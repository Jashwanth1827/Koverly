# Daily Update

This folder is a running development log for the Koverly app.

Whenever the user says **"save work"**, a new dated entry is written here
describing everything that was changed, modified, or added — with enough
detail to understand and reproduce the work later.

## Naming convention

One file per day: `YYYY-MM-DD.md`

If multiple save-work requests happen on the same day, the latest entry
**appends** to that day's file as a new timestamped section rather than
overwriting earlier entries.

## What each entry includes

- Date and time of the save
- Summary of the session
- Files changed, with what changed and why
- New files created
- Dependency changes
- Tests run and their results
- Verification steps performed
- Known issues / follow-ups
