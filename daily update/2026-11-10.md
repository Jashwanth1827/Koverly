### High-level summary

1. **Pipeline convergence** — remote's taxonomy-driven automatic understanding
   is now canonical: `app/ai/taxonomy.py` vocabularies,
   `AIProvider.extract_candidates()` with bundle segmentation, candidate review
   flow persisted in `document_analyses` / `policy_candidates` /
   `policy_candidate_fields`, legacy `policy_extractions` kept for the older
   review flow.
2. **OCR convergence** — RapidOCR fully removed; self-hosted Tesseract
   (pytesseract + pdf2image + poppler) is the only OCR path, per
   `app/utils/text_extract.py`'s `TextResult` contract. `utils/ocr.py` is now
   a thin `ocr_available()` shim. Alembic dropped entirely (remote keeps
   `Base.metadata.create_all`; no migration tool — variable attributes go in
   `metadata_json`).
3. **Multi-format port** — our XLSX/XLS/CSV/Markdown support ported into the
   remote's format layer: `_extract_spreadsheet`/`_extract_csv` branches in
   `text_extract.py`, content-sniffing for the new types in `storage.py`
   (XLSX detected via `xl/workbook.xml` part, textual validation for CSV/MD),
   union of both upload allowlists (PDF, JPG/PNG/WEBP, DOCX, DOC, RTF, TXT,
   XLSX, XLS, CSV, MD).
4. **Extraction port + hardening** — our improvements ported into the remote's
   `null_provider.py` rather than keeping our file: `_clean_layout()`
   (Markdown emphasis/table pipes/CSV commas/parenthetical label qualifiers →
   `Label: value`), insurer prose fallbacks (`_COMPANY_NAME`,
   `_COMPANY_CORPORATION` for "Life Insurance Corporation of India"-style
   names), insurer/TPA trailing-punctuation strip. Tightened the remote's two
   insurer heading patterns with `(?-i:...)` case-sensitive capitalised-prefix
   groups — compiled with `re.IGNORECASE`, plain `[A-Z]` matched prose — so
   sentences like "We are pleased to issue you Insurance Company details" no
   longer masquerade as the insurer, while every remote fixture still passes.
5. **Test conventions adopted from remote** — spaced policy numbers preserved
   verbatim (`1234 5678 9012 3456 000`), honorifics stripped from names
   (`MR RAHUL SHARMA` → `RAHUL SHARMA`), Indian money format kept verbatim,
   generic zips rejected at sniff with 422. Our tests updated accordingly
   (nominee test-data renamed to avoid `_LABEL_STOP` collisions; zip test
   rewritten to expect upload-time rejection).
6. **PII redactions** — the remote's `test_documents.py` carried real names and
   a real spaced policy number (already public on GitHub via their push);
   replaced with synthetic values (`A B Samplefield`, `A C Sampleperson`,
   synthetic spaced number) and updated assertions. Same treatment for a real
   policy number in a `null_provider.py` comment. Repo-wide PII scan clean;
   `backend/.env`/`frontend/.env` remain gitignored.
7. **Deterministic lint** — root cause found: local ruff ran a user-global
   ~ALL config while CI ran bare defaults, so the two never agreed. Added a
   repo-level `[tool.ruff]` to `backend/pyproject.toml` (explicit select:
   E4/E7/E9, F, I, B, C4, DTZ, PIE, RUF, UP, FURB, ISC, BLE; justified
   ignores: DTZ011 local calendar dates, UP042 str-Enum churn, ISC001;
   FastAPI `Query`/`Depends` as immutable calls for B008; conftest's
   intentional post-env E402). Cleaned all 69+ findings: unused
   imports/variables/noqa (37 auto-fixed), stale `datetime.utcnow()` →
   `datetime.now(UTC)` in candidate/extraction services, `zip(strict=True)`,
   `startswith` tuples, parenthesised string concatenation in collections,
   unused loop/unpacked variables in tests, readiness-probe `noqa: BLE001`
   with justification.
8. **Frontend** — duplicate `documentApi.get` key (merge artifact) removed;
   typecheck and build clean. ESLint step remains a no-op in CI (`|| true`):
   no flat-config exists yet — follow-up.
